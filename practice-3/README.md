# Практическая работа № 3 — предобработка данных

**Студент:** Райымбердиев Исхак

**Уровень:** B

**Датасет:** Titanic (`titanic.csv`)

## Цель

Собрать воспроизводимый пайплайн подготовки данных для машинного обучения без утечки информации из тестовой выборки.

## Что выполнено

- данные разделены на train и test до обучения преобразований;
- числовые пропуски заполняются медианой, затем признаки масштабируются;
- категориальные пропуски заполняются модой, категории кодируются через One-Hot Encoding;
- для признака `deck` используется отдельная категория `Unknown`;
- `ColumnTransformer` объединяет числовой и категориальный пайплайны;
- `handle_unknown="ignore"` позволяет обрабатывать новые категории в test;
- показаны размерности матриц до и после преобразований;
- проверено, что преобразования обучены только на train.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter notebook titanic_preprocessing.ipynb
```
