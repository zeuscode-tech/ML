# Практическая работа №13 — Нейронные сети

## Цель работы

Обучить многослойный персептрон на табличных данных, исследовать влияние архитектуры сети и сравнить MLP с градиентным бустингом.

## Данные

Использован датасет оттока клиентов `o_churn_synthetic.csv`.

- Объектов: 3000
- Целевая переменная: `churn`
- Класс 0: 1886 объектов
- Класс 1: 1114 объектов
- Пропусков: 0

Признак `subscriber_code` удалён как идентификатор.

## Предобработка

Категориальные признаки `region` и `tariff` кодируются через `OneHotEncoder`.

Числовые признаки масштабируются через `StandardScaler`. Предобработка и модель объединены в `Pipeline`, поэтому утечки данных нет.

## Уровень A — подбор архитектуры MLP

Проверены архитектуры:

- `(16,)`
- `(32,)`
- `(64,)`
- `(32, 16)`
- `(64, 32)`

Архитектуры сравнивались через трёхкратную кросс-валидацию по ROC-AUC.

Лучшей была выбрана архитектура `(16,)`.

Итоговый результат MLP:

- Accuracy test: 0.7450
- F1 test: 0.6185
- ROC-AUC test: 0.8005
- Количество эпох: 57

Ранняя остановка завершила обучение до достижения максимальных 500 эпох.

## Уровень B — сравнение с XGBoost

| Модель | Accuracy test | F1 test | ROC-AUC test | Время |
|---|---:|---:|---:|---:|
| MLP | 0.7450 | 0.6185 | 0.8005 | 0.1756 с |
| XGBoost | 0.7383 | 0.5858 | 0.7884 | 0.0773 с |

MLP показала более высокие F1 и ROC-AUC, но обучалась дольше.

### Устойчивость

| Модель | Средний ROC-AUC | Стандартное отклонение | Средний F1 |
|---|---:|---:|---:|
| MLP | 0.7887 | 0.0181 | 0.5945 |
| XGBoost | 0.7884 | 0.0000 | 0.5858 |

MLP немного лучше в среднем, но чувствительнее к начальной инициализации весов.

## Уровень C — нейронная сеть на NumPy

Реализована нейронная сеть с одним скрытым слоем без использования `MLPClassifier`.

Реализованы:

- прямое распространение;
- функции активации ReLU и tanh;
- sigmoid в выходном слое;
- бинарная кросс-энтропия;
- обратное распространение ошибки;
- обновление весов градиентным спуском;
- численная проверка градиентов.

Максимальная относительная ошибка проверки градиентов:

`2.58 × 10⁻⁸`

Ошибка значительно меньше `10⁻⁵`, поэтому backpropagation реализован правильно.

| Реализация | Активация | Accuracy test | ROC-AUC test |
|---|---|---:|---:|
| NumPy | ReLU | 0.9267 | 0.9794 |
| sklearn | ReLU | 0.9533 | 0.9913 |
| NumPy | tanh | 0.8800 | 0.9520 |
| sklearn | tanh | 0.9533 | 0.9906 |

Лучший результат показал `sklearn MLPClassifier` с ReLU.

Реализация sklearn быстрее и точнее, поскольку использует оптимизатор Adam. Ручная реализация использует обычный градиентный спуск.

## Вывод

Нейронная сеть может конкурировать с XGBoost на данном датасете, но её преимущество небольшое и зависит от инициализации весов.

Для табличных данных умеренного размера XGBoost остаётся быстрым и устойчивым вариантом. Применение MLP оправдано только в случае подтверждённого преимущества на кросс-валидации.
