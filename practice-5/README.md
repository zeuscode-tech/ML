# Практическая работа № 5. Классификатор и анализ метрик

**Уровень B. Подбор порога классификации с учётом цены ошибки.**

## Задача

На данных IBM Telco Customer Churn построена модель, предсказывающая уход клиента телеком-компании. Положительный класс — уход клиента (`Churn = 1`).

Принята следующая цена ошибок:

- `FN = 5`: уходящий клиент не выявлен, компания теряет клиента;
- `FP = 1`: клиенту без реального риска ухода сделано лишнее удерживающее предложение.

Порог выбирается на validation-выборке по минимуму функции `5 × FN + FP`. Окончательное сравнение проводится на отдельной test-выборке.

## Результаты

Модель: логистическая регрессия с единым pipeline предобработки числовых и категориальных признаков.

- ROC-AUC: **0,832**;
- PR-AUC: **0,622**;
- выбранный порог: **0,17**.

| Метрика | Порог 0,5 | Порог 0,17 |
|---|---:|---:|
| Precision | 0,618 | 0,448 |
| Recall | 0,527 | 0,901 |
| F1 | 0,569 | 0,599 |
| FN | 177 | 37 |
| FP | 122 | 415 |
| Стоимость ошибок | 1007 | 600 |

Порог 0,17 сокращает число пропущенных уходящих клиентов со 177 до 37 и уменьшает принятую стоимость ошибок с 1007 до 600. Precision снижается из-за роста количества ложных тревог, но такой компромисс соответствует условию, что FN в пять раз дороже FP.
