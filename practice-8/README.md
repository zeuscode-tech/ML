# Практическая работа № 8. Градиентный бустинг

## Цель

Продолжить сравнение ансамблевых моделей из практической работы № 7: обучить градиентный бустинг для прогноза оттока клиентов, настроить его через отдельную validation-выборку и сравнить со случайным лесом и логистической регрессией.

## Данные

Использован предоставленный файл `o_churn_synthetic.csv`:

- 3000 клиентов и 13 столбцов;
- целевая переменная `churn`: 1 — клиент ушёл, 0 — остался;
- `subscriber_code` удалён как идентификатор;
- категориальные признаки `region` и `tariff` преобразованы через `OneHotEncoder`;
- доля класса `churn=1` — 37,13%;
- train/test — 2400/600, стратифицированное разбиение 80/20;
- для всех моделей использован `random_state=42`.

Разбиение выполняется до обучения предобработки. Для настройки XGBoost из train отдельно выделены 1920 строк для обучения и 480 строк для validation. Тестовая выборка не использовалась при подборе параметров.

## Случайный лес и базовый XGBoost

На одном и том же разбиении сравнивались случайный лес из 100 деревьев и XGBoost с 300 деревьями.

| Модель | F1 train | F1 test | ROC-AUC test |
|---|---:|---:|---:|
| Случайный лес, 100 деревьев | 1,0000 | 0,5515 | 0,7555 |
| XGBoost, базовые параметры | 0,7910 | 0,5663 | 0,7774 |

Случайный лес полностью запомнил обучающие данные, но значительно хуже работает на test. Разрыв между `F1 train` и `F1 test` показывает переобучение. Базовый XGBoost дал более высокий F1 и ROC-AUC на тестовой выборке.

## Настройка XGBoost

Проверены 12 сочетаний параметров:

```text
learning_rate = [0.3, 0.1, 0.05, 0.01]
max_depth = [3, 4, 6]
```

Для каждого сочетания разрешалось до 3000 деревьев. `early_stopping_rounds=50` останавливал обучение, если validation logloss не улучшался 50 итераций подряд.

Лучший результат на validation:

```text
learning_rate = 0.1
max_depth = 3
n_estimators = 70
validation ROC-AUC = 0.7819
```

Уменьшение `learning_rate` требовало большего количества деревьев. Небольшая глубина показала лучший результат, поскольку глубокие деревья сильнее подстраивались под обучающие данные.

## Итоговое сравнение

Все финальные модели заново обучены на одинаковой train-выборке и один раз оценены на одинаковой test-выборке.

| Модель | F1 train | F1 test | ROC-AUC test | Время обучения, с |
|---|---:|---:|---:|---:|
| Логистическая регрессия | 0,5940 | **0,6111** | **0,8062** | ≈0,01 |
| Случайный лес | 1,0000 | 0,5515 | 0,7555 | ≈0,10 |
| Настроенный XGBoost | 0,6500 | 0,5858 | 0,7884 | ≈0,07 |

Настроенный XGBoost превзошёл случайный лес по F1 и ROC-AUC и уменьшил разрыв между train и test. Однако лучший результат на этом датасете показала логистическая регрессия. Более сложная модель не гарантирует лучшее качество, поэтому итоговый выбор следует делать по метрике на новых данных, а не по сложности алгоритма.
