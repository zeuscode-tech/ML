# Практическая работа № 1 — первичный анализ данных

**Студент:** Райымбердиев Исхак

**Уровень:** B

**Датасет:** Student Performance (`data/student-mat.csv`)

## Цель

Подготовить воспроизводимое Python-окружение и выполнить первичное знакомство с данными: определить размер таблицы, типы признаков, пропуски, основные статистики и построить первые визуализации.

## Что выполнено

- настроено изолированное окружение;
- загружен датасет и показаны первые строки;
- проверены размерность, типы, пропуски и дубликаты;
- рассчитаны описательные статистики;
- признаки разделены на числовые и категориальные;
- построены распределение итоговой оценки и сравнение оценок по полу;
- сформулированы выводы по результатам анализа.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter notebook notebooks/practice_1.ipynb
```

Ноутбук рассчитан на запуск как из каталога `practice-1`, так и из корня репозитория.
