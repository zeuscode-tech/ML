# Практическая работа №10. Кластеризация данных

## Цель

Применить методы обучения без учителя, определить количество кластеров, интерпретировать сегменты и сравнить K-Means, DBSCAN и иерархическую кластеризацию.

## Запуск

1. `python3 -m venv .venv`
2. `source .venv/bin/activate`
3. `pip install -r requirements.txt`
4. `python3 clustering_practice.py`
5. `python3 clustering_advanced.py`
6. `python3 kmeans_numpy.py`

## Уровни A и B

Использован набор из 360 искусственных клиентов с признаками:

- годовые расходы;
- количество посещений в месяц;
- средний чек.

Перед кластеризацией признаки масштабированы через `StandardScaler`.

### Выбор количества кластеров

Проверены значения `k` от 2 до 10.

| k | Инерция | Силуэт |
|---:|---:|---:|
| 2 | 445.73 | 0.545 |
| 3 | 188.46 | 0.590 |
| 4 | 169.15 | 0.463 |
| 5 | 151.02 | 0.347 |

Выбрано `k=3`, потому что при этом значении наблюдается локоть на графике инерции и максимальный коэффициент силуэта `0.590`.

### Профили кластеров

| Кластер | Годовые расходы | Посещения | Средний чек | Название |
|---:|---:|---:|---:|---|
| 0 | 309.78 | 3.30 | 82.43 | Экономные клиенты |
| 1 | 655.00 | 8.90 | 124.63 | Регулярные клиенты |
| 2 | 959.67 | 5.93 | 192.42 | Премиальные клиенты |

Проверка с другим `random_state` дала `Adjusted Rand Index = 1.0`. Состав кластеров не изменился, следовательно, результат устойчив.

## Уровень C

Для сравнения методов использованы данные `make_moons` невыпуклой формы. Истинные метки не передавались алгоритмам и использовались только после обучения для проверки через ARI.

| Метод | Кластеров | Шум | Силуэт | ARI |
|---|---:|---:|---:|---:|
| K-Means | 2 | 0 | 0.494 | 0.445 |
| DBSCAN | 2 | 0 | 0.386 | 1.000 |
| Иерархический | 2 | 0 | 0.386 | 1.000 |

K-Means плохо восстановил полумесяцы, потому что предполагает компактные кластеры около центров. DBSCAN и иерархическая кластеризация с `single linkage` правильно восстановили форму данных.

Несмотря на более высокий силуэт K-Means, его ARI оказался ниже. Силуэт предпочитает компактные округлые группы и не всегда правильно оценивает кластеры сложной формы.

## K-Means на NumPy

Алгоритм самостоятельно реализован без готового класса `KMeans`.

Этапы:

1. выбор начальных центров;
2. расчёт расстояний;
3. назначение ближайшего центра;
4. пересчёт центров как среднего точек;
5. повторение до сходимости.

Результат:

- объектов: 150;
- кластеров: 3;
- итераций: 2;
- SSE: 229.717.

## Вывод

K-Means хорошо работает с компактными округлыми кластерами. DBSCAN подходит для групп сложной формы и способен находить шум. Иерархическая кластеризация показывает последовательность объединения объектов через дендрограмму. Выбор метода должен зависеть от формы данных, плотности и практического смысла сегментов.
