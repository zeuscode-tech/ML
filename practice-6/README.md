Реализовать собственную предобработку текста, выполнить TF-IDF-векторизацию и обучить классификатор SMS-сообщений.

## Данные

Использован открытый датасет SMS Spam Collection из UCI Machine Learning Repository.

Классы несбалансированы, поэтому качество оценивается не только по accuracy, но и по precision, recall и F1 для класса `spam`.

## Предобработка текста

До векторизации выполняются следующие операции:

1. Приведение текста к нижнему регистру.
2. Нормализация английских отрицаний.
3. Токенизация с помощью регулярного выражения.
4. Удаление пунктуации.
5. Удаление цифр.
6. Удаление английских стоп-слов.

Отрицания `no`, `not`, `never` и `nor` не удаляются, поскольку они могут менять смысл сообщения.

Пример:

```text
До:
Nah I don't think he goes to usf, he lives around here though

После:
nah not think goes usf lives
```

Стемминг и лемматизация не использовались. Для коротких SMS это не являлось обязательным, а сохранение исходной формы слов упрощает анализ ошибок.

## Разделение данных

Данные разделены на обучающую и тестовую выборки с сохранением соотношения классов:

| Выборка | Количество сообщений |
|---|---:|
| Train | 4457 |
| Test | 1115 |

Использованы параметры:

```python
test_size=0.20
random_state=42
stratify=data["label"]
```

Сначала выполняется разбиение данных, и только затем TF-IDF обучается на тренировочной выборке. Благодаря этому тестовые сообщения не участвуют в построении словаря и утечки данных нет.

## TF-IDF

Использованы параметры:

```python
TfidfVectorizer(
    min_df=2,
    max_df=0.95,
    max_features=5000,
    ngram_range=(1, 2),
    sublinear_tf=True,
)
```

`min_df=2` удаляет слова, встретившиеся только один раз. `max_df=0.95` удаляет слова, встречающиеся почти во всех документах. Ограничение `max_features=5000` не позволяет словарю неограниченно увеличиваться.

Размерность полученной обучающей матрицы:

```text
(4457, 5000)
```

Таким образом, каждое сообщение представлено вектором из 5000 числовых признаков.

## Модель

Использован наивный байесовский классификатор:

```python
MultinomialNB(alpha=0.5)
```

Он подходит для разреженных неотрицательных признаков TF-IDF и часто используется как базовая модель классификации текстов.

Полный процесс реализован через `sklearn.pipeline.Pipeline`:

```text
исходный текст
      ↓
собственная очистка
      ↓
TF-IDF
      ↓
Multinomial Naive Bayes
      ↓
класс ham или spam
```

| Метрика | Значение |

| Recall для spam | 0,8389 |
| F1 для spam | 0,9124 |

Матрица ошибок:

| Истинный класс | Предсказан ham | Предсказан spam |

| ham | 966 | 0 |
| spam | 24 | 125 |

### Интерпретация

Accuracy 97,85% означает, что модель правильно классифицировала примерно 98 сообщений из 100.

Precision 100% означает, что все сообщения, названные моделью спамом, действительно были спамом. Ложноположительных ошибок не было.

Recall 83,89% означает, что модель обнаружила 125 из 149 спам-сообщений. Оставшиеся 24 спам-сообщения были ошибочно отнесены к обычным.

F1 равен 0,9124 и отражает общий баланс между precision и recall.

Из-за дисбаланса классов accuracy нельзя рассматривать отдельно: модель может показать высокую accuracy, просто чаще выбирая преобладающий класс `ham`.

## Анализ пяти ошибок

Подробный анализ находится в файле `error_analysis.md`.

Основные причины ошибок:

1. Спам маскируется под обычную личную переписку.
2. В сообщении отсутствуют типичные рекламные слова.
3. Частное объявление похоже на нормальное сообщение.
4. Опечатки и слитные слова создают неизвестные токены.
5. SMS-сокращения и замена букв цифрами ухудшают распознавание.
6. Удаление телефонных номеров и цен приводит к потере полезных признаков.

Все пять наиболее уверенных ошибок оказались ложноотрицательными: модель предсказала `ham`
