## Структура практических работ

В папках находятся:

- исходный код и Jupyter Notebook;
- используемые данные или инструкция по их получению;
- результаты экспериментов в CSV/TXT;
- графики и визуализации;
- отдельный README с запуском, результатами и выводами;
- `requirements.txt` с зависимостями.

## Основные инструменты

- Python, NumPy и pandas;
- matplotlib и seaborn;
- scikit-learn;
- XGBoost, Optuna и UMAP в соответствующих работах;
- Jupyter Notebook;
- Git и GitHub.

## Общий запуск

Перейдите в папку нужной практической работы и выполните:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Точная команда запуска указана в README выбранной практической работы.

## Проверка репозитория

Запуск единой проверки:

```bash
python3 check_all.py
```

Та же команда автоматически выполняется в GitHub Actions при каждом `push` и `pull request`.

Проверено:

- присутствуют все папки `practice-1`–`practice-13`;
- в каждой работе есть README и файл зависимостей;
- все отслеживаемые Python-файлы проходят синтаксическую проверку;
- ноутбуки ПР-1–ПР-5 сохранены с выполненными ячейками и без ошибок;
- внутренние ссылки README ведут к существующим файлам;
- виртуальные окружения, кэш Python и системные файлы не добавлены в Git.
