# Практическая работа №11 — Снижение размерности

## Цель работы

Исследовать методы снижения размерности PCA, t-SNE и UMAP, построить двумерные визуализации и проверить влияние PCA на качество классификации.

## Данные

Использован встроенный датасет `Breast Cancer Wisconsin` из scikit-learn.

- Объектов: 569
- Исходных признаков: 30
- Класс 0: злокачественная опухоль
- Класс 1: доброкачественная опухоль
- Пропусков: 0

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 pca_practice.py
python3 pca_advanced.py
```

## Уровень A — PCA

Все признаки перед PCA масштабированы через `StandardScaler`.

- Исходных признаков: 30
- Первые две компоненты сохраняют 63,24% дисперсии
- Для сохранения 90% дисперсии достаточно 7 компонент

График `explained_variance.png` показывает накопленную объяснённую дисперсию, а `pca_2d.png` — двумерную проекцию объектов.

## Уровень B — PCA в классификации

Масштабирование и PCA помещены внутрь `Pipeline`, поэтому они обучаются только на тренировочной выборке. Утечки данных нет.

| Модель | Признаков | Accuracy test | ROC-AUC |
|---|---:|---:|---:|
| Без PCA | 30 | 0.9860 | 0.9977 |
| PCA 80% | 5 | 0.9650 | 0.9948 |
| PCA 90% | 7 | 0.9650 | 0.9956 |
| PCA 95% | 10 | 0.9790 | 0.9973 |

Максимальное качество показала модель без PCA. Однако PCA 95% сократил число признаков с 30 до 10 почти без потери качества.

## Уровень C — PCA, t-SNE и UMAP

| Метод | Время | Trustworthiness | Поддерживает transform |
|---|---:|---:|---|
| PCA | 0.002 с | 0.8713 | Да |
| t-SNE | 1.435 с | 0.9519 | Нет |
| UMAP | 4.912 с | 0.9280 | Да |

PCA является самым быстрым и подходит для ML-пайплайна. t-SNE лучше сохранил локальное соседство, но не имеет обычного `transform` для новых объектов, поэтому применяется преимущественно для визуализации. UMAP сохраняет локальную структуру и поддерживает преобразование новых объектов.

Для t-SNE проверены значения `perplexity` 5, 30 и 50. Лучший результат получен при `perplexity=30`: trustworthiness равен 0.9519.

## Итоговый вывод

PCA оправдан, когда требуется сократить размерность, ускорить модель или визуализировать многомерные данные. На этом датасете PCA не повысил качество классификации, но позволил уменьшить число признаков почти без потери ROC-AUC.

t-SNE лучше использовать для визуального исследования данных. UMAP является компромиссом между качеством локальной структуры и возможностью преобразования новых объектов.
